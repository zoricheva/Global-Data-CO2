# Global-Data-CO2

Репозиторий предназначен для демонстрации курсового проекта по курсу «Data Science Pro» на тему «Прогнозирование выбросов углекислого газа в атмосферу в результате потребления энергии».

Основная задача
Создать модель, которая будет прогнозировать выбросы углекислого газа в разных странах, основываясь на данных трех основных видов потребления энергии.

Виды потребления энергии:
- Электричество из ископаемого топлива (ТВт·ч): Электроэнергия, вырабатываемая из ископаемого топлива (уголь, нефть, газ) в тераватт-часах.
- Электричество из ядерной энергии (ТВт·ч): Электроэнергия, вырабатываемая из ядерной энергии в тераватт-часах.
- Электроэнергия из возобновляемых источников (ТВт·ч): Электроэнергия, вырабатываемая из возобновляемых источников (гидроэнергия, солнечная энергия, энергия ветра и т. д.) в тераватт-часах.

  Для реализации данной задачи был взят датасет Global Data on Sustainable Energy за 2000-2020 года.

В функционал приложения входят следующие действия:
1) строка для введения числовых данных электроэнергии из ископаемого топлива (уголь, нефть, газ) в числовом формате;
2) строка для введения числовых данных электроэнергии из атомной энергетики;
3) строка для введения числовых данных электроэнергии из возобновляемых источников таких, как гидроэнергия, солнечная энергия и ветер;
4) отправка данных;
5) вывод предсказания количества СО2;


  Инструкция использования:
1) загрузите репозиторий Github проекта по ссылке; 
https://github.com/zoricheva/Global-Data-CO2/tree/Prediction-CO2
2) откройте Visual Studio для локальной загрузки или Render.com для онлайн загрузки;
3) установите python 3.9.9 или более новые версии, pip install flask и все необходимыми зависимости, указанными в файле requirements.txt;
4) запустите код файла add.py для локальной загрузки;
5) для онлайн загрузки 
- в Render создайте новый проект;
- укажите ссылку на репозиторий;
- выберите ветку Prediction CO2;
- укажите язык Python3, pip install requirements.txt, gunicorn app:app;
- запуск приложения;
6) запустите полученную ссылку на html страницу;
7) на открывшейся странице введите числовые данные в строки;
8) нажмите кнопку «Отправить»;
9) результат предсказания отобразится на странице.
